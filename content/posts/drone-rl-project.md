## 项目背景
作为空天机械方向的研究生，我对无人机自主飞行充满兴趣。本项目使用深度强化学习训练四旋翼在未知障碍环境中完成高速避障。

## 仿真环境
- 基于 AirSim + Unreal Engine
- 自定义森林场景，随机生成树木

## 算法
- 采用 SAC 算法，状态为单目 RGB 图像和 IMU 数据
- 奖励函数包含前进速度、碰撞惩罚、平滑性

## 实验结果
- 在陌生场景中成功率超过 85%
- 通过 domain randomization（光照、纹理变化）提高了 sim-to-real 潜力

## 踩坑记录
- 训练初期撞机过多导致探索不足，加入好奇心驱动缓解
- AirSim 在 Windows 下性能不佳，迁移到 Linux + Docker 后 FPS 提升 40%
