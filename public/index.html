论文精读：OpenVLA — 开源视觉-语言-动作模型

动机 RT-2 虽然强大，但模型闭源且规模过大（55B），普通实验室难以复现和微调。OpenVLA 使用 7B 参数的 VLM，完全开源，并验证了较小的 VLA 也能取得竞争力性能。 方法 基于 Prismatic-7B VLM，使用 SigLIP 作为视觉编码器 动作通过离散化 token 表示，与文本 token 拼接后自回归生成 在 Open X-Embodiment 数据集上微调 关键结果 在多个真实机器人任务上泛化能力接近 RT-2-X（55B），但模型大小仅 7B 支持 LoRA 微调，可在消费级 GPU 上完成 我的思考 OpenVLA 是当前开源社区的事实标准，面试中被问“你用过哪些 VLA 模型”时可直接引用。它的轻量化设计也使得学术研究更容易迭代。

无人机强化学习避障项目总结

项目背景 作为空天机械方向的研究生，我对无人机自主飞行充满兴趣。本项目使用深度强化学习训练四旋翼在未知障碍环境中完成高速避障。 仿真环境 基于 AirSim + Unreal Engine 自定义森林场景，随机生成树木 算法 采用 SAC 算法，状态为单目 RGB 图像和 IMU 数据 奖励函数包含前进速度、碰撞惩罚、平滑性 实验结果 在陌生场景中成功率超过 85% 通过 domain randomization（光照、纹理变化）提高了 sim-to-real 潜力 踩坑记录 训练初期撞机过多导致探索不足，加入好奇心驱动缓解 AirSim 在 Windows 下性能不佳，迁移到 Linux + Docker 后 FPS 提升 40%
